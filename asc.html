How a code works

Every code is a string in the form PREFIX-BODY, e.g. ASL-FOUNDERS-001 or DRF-7F4A-BLOOM. Three uppercase ASCII letters, a dash, then any combination of letters, digits, dashes, or section marks.

The full string is hashed with FNV-1a 32-bit. From that hash, two properties are derived deterministically: a tier (1–4, weighted toward low tiers) and a hidden flag (~40% rate). Same string, same parse, every time, on every device, in every Asleepius product. No server lookup needed for the deterministic layer.

For products that meter real compute (DriftMetrics scrapes, future paid features) there's a second layer: a server-side row keyed on the canonical code string with a balance column. Each redemption decrements the balance atomically. When the balance hits zero, the code still parses (Layer 1 still works) but no longer grants metered access.

How to get a code

Codes are issued manually by Asleepius Games. Until that changes:

  • Hand-printed cards at indie dev events.
  • Drops in our other products (Shred Crawler, future game releases).
  • Direct ask if you've contributed to the Asleepius ecosystem in some way.
  • Eventually: paid via Ko-fi for a code in the thank-you reply.

There is no signup form, no waitlist, no tiered subscription. There may never be. The goal is to keep the access model legible and the gating low-friction once you're in.

Privacy

Your code lives in your browser's localStorage. We never see who you are; we only see that some request submitted a code that decrements one row in our codes table by one. We don't know which IP, browser, or device burned a use — only that a use happened.

Codes are sharable by design. If you paste your code on Twitter, anyone can use it until the balance runs out. That's intentional. The system rewards possession, not identity.
