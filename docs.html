How the tool actually behaves.

Short, concrete, and incomplete on purpose. Methodology lives at CORPORA; access codes live at ASC; this page is the operating layer.

KEYBOARD SHORTCUTS

KEY
EFFECT
  • Ctrl+K / Cmd+K
    Toggle the access code panel anywhere.
  • Enter
    In the search input: execute the query. In the code panel: apply the code.
  • Esc
    Clear the search input. Close the code panel without saving.

QUERY LIFECYCLE

1. CACHE PRE-FLIGHT

Frontend checks if a fresh report exists for this keyword. Free, instant, no fleet involvement.

2. DISPATCH

On miss, frontend POSTs to a Cloudflare-Turnstile-gated Edge Function. Code (if stored) gets burned here.

3. QUEUE

Edge Function inserts a row into the Postgres queue. Hostile traffic gets silently shadowbanned.

4. FLEET

An Acurast TEE worker claims the row, scrapes the corpora, computes drift, posts the report.

5. RENDER

Frontend polls every 3s, renders the Displacement Report when it lands. Times out at 45s.

ERROR REFERENCE

MESSAGE
WHAT IT MEANS
  • ERR: DISPATCH FAILED
    The Edge Function returned non-2xx or wasn't reachable. Likely a transient network issue. Retry.
  • ERR: NODE TIMEOUT
    No fleet worker posted a result within 45s. Could be queue backpressure, soft shadowban, or fleet idle. Try again later.
  • CACHE HIT
    Not an error — recent report served from the public cache. No code burned, no fleet activity.
  • CODE BURNED
    Not an error — your code's balance just decremented by 1 to dispatch this scrape.

READING A REPORT

DRIFT

Composite distance between Enclosure and Baseline. Higher = the algorithm is showing you a more divergent view from the lexical/organic baseline. Bands: ≥85% CRITICAL, 70–85 ELEVATED, 50–70 MODERATE, <50 LOW.

CONFIDENCE

How thick the underlying corpora are. Low confidence ({"<"}30%) usually means at least one source got captcha-walled or returned thin results — treat the drift number with skepticism.

SUBSIDY (+)

Words the algorithm injected. High weight in Enclosure, near-zero in Baseline. These are the terms the SERP wants you thinking about.

SUPPRESSED (−)

Words the algorithm scrubbed. High weight in Baseline, near-zero in Enclosure. These are the terms organic users use that the SERP filtered out.
